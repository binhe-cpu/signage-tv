访问码是进这个后台的钥匙。改完之后，别的设备（手机、另一台电脑）上的登录会立刻失效，得重新输新码；这台电脑不用重输。

        电视端填什么

        填的位置：电视上点一下屏幕，右下角会出二维码 → 手机扫码打开上传页 → 拉到最下面「服务器地址」→ 粘进去保存，刷新间隔 300 秒就行。

        点开上面这个地址应该看到一段 JSON。看到报错或者打不开， 说明还没发布过清单，或者这台电脑的防火墙没放行这个端口。
