# 门店屏（SignageTV）

安卓电视/盒子上循环播放图片和视频。10 块屏以内的门店自用，不做多用户后台。
素材在电脑上做好推上去、屏自己来拉；临时换的扫屏幕上的码直传；不在店里用网页后台改。

## 现在到哪一步

| 步骤 | 状态 | 内容 |
|---|---|---|
| 第 1 步 | 完成 | 单机循环播放、全屏常亮、开机自启 |
| 第 2 步 | 完成 | 远端播放清单 + 素材增量同步 + 电脑端发布工具 |
| 第 3 步 | 完成 | 手机扫码上传：传素材、删任何来源的素材、看素材内容、改服务器地址；可给页面加访问码，设了码电视点屏也要先输码 |
| 第 4 步 | 部分 | Kiosk 加固：播放看门狗、定时重扫已完成；定时重启、封返回键、崩溃自恢复、切图消黑屏未做 |
| 第 5 步 | 完成 | 网页后台：浏览器里管内容、传素材、调顺序、一键发布（空清单也能发 = 下架全部）、改访问码、十块屏的状态回传 |

## 素材从哪来

```
① 手机扫码上传（优先级最高）
   点屏幕出二维码 → 手机同 WiFi 扫码 → 选图/视频 → 传进电视，传完立刻插播

② 远端清单（配了就用它）
   每 5 分钟拉一次 playlist.json，比对 size / sha256 增量下载，按时段和星期过滤后播放

③ 本地目录（兜底）
   扫素材根目录下的 media/（含子目录），按文件名升序循环，每 15 秒重扫一次
```

播放列表 = ① + （②或③）。远端拿不到东西会自动退回本地目录，屏不会黑；拉失败就用上次缓存的清单接着播。

删素材：点屏（设了访问码就先输码）扫码打开页面，下半部分列出三条路来的全部素材，每条标着出处。手机传的和本地的随手能删，十几秒生效；远端的不给删，要下架得改电脑端的清单（见第五节）。

## 一、编译

双击 `build.bat`，或者：

```bash
sh build.sh
```

产物在 `app/build/outputs/apk/debug/`，文件名形如 `signage-0.3.9-12-debug.apk`。
版本号只改 `app/build.gradle.kts` 开头的 `appVersionCode` / `appVersionName`，改完重编，文件名和包内记录的版本一起变。

核对电视上装的是哪一版：点一下屏幕（遥控器按「确定」）呼出二维码，卡片底部写着 `门店屏 v0.3.9 (12)`。

### 不想用本机环境，让 GitHub 编

代码推上去，GitHub 自动编三样：APK、网页后台 exe、最小容器镜像（Alpine 约 70MB，推到 GitHub Packages 可直接 `docker pull`，另附群晖能导入的 tar.gz）。本机不用装 JDK 和 Android SDK。

打一个 `v` 开头的 tag 还会生成 Release，产物直接下载：

```bash
git tag v0.3.9 && git push origin v0.3.9
```

公开仓库不花钱。细节（在哪看结果、怎么固定签名、出问题怎么查）见 [docs/ci.md](docs/ci.md)。

### 本机编译环境

| 组件 | 位置 |
|---|---|
| JDK 17 | `D:\jdk17\jdk-17.0.20.1+1`（Temurin 完整版，必须带 `jlink`） |
| Android SDK | `D:\android-sdk`（platform-34 / build-tools-34.0.0 / platform-tools，许可已接受） |
| Gradle 8.7 | `D:\gradle-8.7`，依赖缓存放 `D:\gradle-home`，别写满 C 盘 |
| adb | `D:\android-sdk\platform-tools\adb.exe` |
| 逻辑测试台 | `D:\android-toolchain\uploadtest`（没真机时跑纯逻辑测试） |

别用 PyCharm 自带的 JBR：那是精简版 JDK，缺 `jlink.exe`，AGP 会在 `compileDebugJavaWithJavac` 阶段失败。`build.bat` 里已经指好了。

## 二、装到电视/盒子

支持 Android 5.0（API 21）及以上。

**U 盘（老电视首选）**：Android 5.x / 6.x 一般不带网络调试，`adb connect` 连不上。

1. APK 拷到 U 盘根目录
2. U 盘插电视，用自带文件管理器找到这个 APK
3. 点它安装。提示「禁止安装」就去 设置 → 安全 → 打开「允许未知来源」

**adb（盒子支持网络调试时）**：设置里开「开发者选项」和「网络调试（ADB）」，跟电脑同一网段。

```bat
D:\android-sdk\platform-tools\adb.exe connect 192.168.1.50:5555
D:\android-sdk\platform-tools\adb.exe install -r app\build\outputs\apk\debug\signage-0.3.9-12-debug.apk
```

文件名换成你实际编出来的。装新版直接 `install -r` 覆盖，电视上的素材和配置不会丢。

报「解析软件包时出现问题」只有两个原因：APK 要求的系统版本高于电视，或者只签了 v2（Android 7.0 以下只认 v1）。`minSdk = 21` 和 `enableV1Signing = true` 就是为这两条立的规矩，改之前先想清楚。

## 三、本地目录（不用联网，最简单）

素材放公共目录 `/sdcard/signage/media`：

```bash
adb push D:\素材\ /sdcard/signage/media/
```

也可以直接插 U 盘、或用电视自带的文件管理器往里拷。这个目录是公开的，任何文件管理器都翻得到（不像 `Android/data/` 下面那样被系统藏起来）。

播放顺序 = 文件名升序，用 `01_`、`02_` 前缀控制，例如 `01_开业促销.mp4`、`02_新品海报.jpg`。

- 每 15 秒自动重扫，新拷进去的十几秒内上屏，不用重启、不用等一轮播完
- 子目录也往下翻（最多 4 层），排序按相对路径。有些电视的文件管理器拷文件时会多建一层，所以做了递归；也可以拿它按活动分批，建个「国庆活动」文件夹丢进去
- 文件名以 `.` 开头的跳过（手机上传写到一半的临时文件靠这个挡掉）

素材根目录是实测出来的，不是写死的：App 启动时按 ① `/sdcard/signage/` → ② `Android/data/com.laodao.signage/files/` → ③ 内部私有目录 的顺序，挨个写一个探针文件试，谁能写用谁。
老电视上 `Android/data` 写不进去是常事（表现是「手机上传来好几个、成功 0 个」），这样会自动退到还能用的地方。实际用的是哪个，手机打开 `/status` 一看就知道。

跑在 Android 6.0～10.0 上首次启动弹一次存储权限，点「允许」；5.x（店里那台）安装时就自动授予了。

## 四、远端清单（多店同步）

### 4.1 素材放哪儿

| 场景 | 方案 | 成本 |
|---|---|---|
| 10 块屏都在同一家店 | 店里一台常开的电脑/NAS，起个静态 HTTP 服务 | 0 |
| 10 块屏分散在不同店 | 对象存储（腾讯云 COS / 阿里云 OSS） | 每月几块钱 |

**局域网**：在店里那台电脑上跑（让它常开）

```bash
cd D:\signage-web
python -m http.server 8000
```

假设这台电脑 IP 是 `192.168.1.10`，清单地址就是 `http://192.168.1.10:8000/playlist.json`。

那台电脑上如果跑着网页后台（`server/`），不用另起 `http.server`：本地目录模式的网页后台自带这个出口，清单地址是 `http://192.168.1.10:8600/playlist.json`，页面上「电视端填什么」那张卡片会直接写出来（带复制按钮）。电脑别睡、防火墙放行端口，见 [server/README.md](server/README.md) 第五节。

**对象存储**：建一个桶，权限设「公有读私有写」，拿到形如 `https://signage-1250000000.cos.ap-shanghai.myqcloud.com/` 的默认域名。完整配置步骤（建桶、子账号密钥、防盗刷、常见坑）见 [docs/cos-setup.md](docs/cos-setup.md)。

### 4.2 在电脑上准备素材目录

```
D:\signage\media\
├── 01_门店形象.jpg
├── 02_秋季促销.jpg
├── 03_新品视频.mp4
├── 04_夜场活动.jpg
└── playlist.preset.json     ← 可选，控制播放顺序和时段
```

`playlist.preset.json` 不写就按文件名的自然顺序播；写了能指定顺序、每张停留多久、几点到几点播、星期几播。样例见 `tools/playlist.preset.example.json`：

```json
{
  "defaults": { "imageDurationSec": 8, "muted": true },
  "items": [
    { "file": "01_门店形象.jpg" },
    { "file": "02_秋季促销.jpg", "durationSec": 10 },
    { "file": "03_新品视频.mp4" },
    { "file": "04_夜场活动.jpg", "startTime": "18:00", "endTime": "22:00" },
    { "file": "05_周末特惠.jpg", "days": [6, 7] }
  ]
}
```

`days` 里 `1`=周一 … `7`=周日。

### 4.3 发布

```bat
cd signage-tv\tools

rem 局域网方案：发到那台电脑的共享目录
publish.bat --src "D:\signage\media" --target "local:D:\signage-web"

rem 对象存储方案（先设好环境变量，见 4.5）
publish.bat --src "D:\signage\media" --target "s3://signage-1250000000/signage"
```

`publish.bat` 自动用装好 boto3 的那个 Python，不用记路径、不用 `pip install`。**在 cmd / PowerShell 里跑，Git Bash 跑不了 `.bat`**。

它会扫素材、算 sha256、只传变过的、生成 `playlist.json`。清单一定最后才写，端侧不会拉到「有清单、没素材」的中间状态。

常用参数：

| 参数 | 作用 |
|---|---|
| `--playlist "playlist-{device}.json"` `--device "A店"` | 10 家店各自一份清单，共用一套素材 |
| `--prune` / `--no-prune` | 是否删掉远端已不在素材目录里的文件（默认开） |
| `--dry-run` | 只打印计划，不动文件 |
| `--no-hash` | 不算 sha256，发布更快（同尺寸换内容检测不到） |
| `--unmuted` | 不静音 |

`--target` 只支持两种：`local:<目录>` 和 `s3://<bucket>/<前缀>`。

### 4.4 让盒子知道去哪儿拉

在盒子上放一个配置文件（和素材同一个根目录，公开可见，文件管理器直接能改）：

```
/sdcard/signage/signage-remote.json
```

具体落在哪个路径由 App 实测决定（见第三节），手机打开 `/status` 能看到实际位置。内容如下（样例见 `tools/signage-remote.example.json`）：

```json
{
  "playlistUrl": "http://192.168.1.10:8000/playlist.json",
  "device": "",
  "refreshIntervalSec": 300,
  "prune": true,
  "assetBaseUrl": ""
}
```

| 字段 | 说明 |
|---|---|
| `playlistUrl` | 必填。清单地址。没有值就退回本地目录模式 |
| `device` | 设备名，替换 `playlistUrl` 里的 `{device}` 占位，如 `playlist-{device}.json` |
| `refreshIntervalSec` | 多久拉一次，默认 300 秒 |
| `prune` | 是否清理盒子上已不在清单里的素材，默认 true |
| `assetBaseUrl` | 素材基址，留空则取清单所在目录 |

```bash
adb push signage-remote.json /sdcard/signage/signage-remote.json
```

不想开电脑也行：扫码打开上传页，在「电脑端清单（服务器地址）」那一栏填好点「保存并立即同步」（见第五节）。10 台屏装同一个 APK，每台在手机页面上改一下设备名即可，不用重新打包、不用 adb。

### 4.5 对象存储的环境变量

```bat
set SIGNAGE_S3_ENDPOINT=https://cos.ap-shanghai.myqcloud.com
set SIGNAGE_S3_REGION=ap-shanghai
set AWS_ACCESS_KEY_ID=子账号的SecretId
set AWS_SECRET_ACCESS_KEY=子账号的SecretKey
```

用子账号的密钥，别用主账号的，原因和建法见 [docs/cos-setup.md](docs/cos-setup.md) 第 3 节。还要 `pip install boto3`（只有用对象存储时才需要）。

### 4.6 验证

```bash
# 电脑上：清单能取到吗
curl http://192.168.1.10:8000/playlist.json

# 盒子上：看日志
adb logcat -s SignageTV
```

日志里会打印类似：

```
远端；清单 8 项，当前时段可播 6 项；下载 2 个 / 跳过 6 个 / 清理 1 个，共 12 MB
```

## 五、手机扫码上传

场景：人在店里，临时想加一张今天的促销图，不想开电脑、不想找 U 盘。

1. 点一下屏幕（触摸屏）；遥控器机型按「确定」或「菜单」
2. 设过访问码的话，电视先弹一层「需要访问码」，输对了才显示二维码。通过后 5 分钟内再点不用重输
3. 二维码浮出来，手机连上和电视同一个 WiFi
4. 用相机或微信扫码打开上传页（页面本身还要再输一次码）
5. 选图片或视频 → 点「开始上传」
6. 传完电视自动插播；页面下半部分列着电视上全部素材，随手能删
7. 再点一下屏幕收起二维码，不管它两分钟后自己收

手机和电视在同一个局域网直连，不经过任何云端服务，店里的宽带断了也照样能用。

### 删素材

页面下半部分列的是电视上的全部素材，三条路来的都在，每条标着出处：

| 标签 | 哪来的 | 能不能删 |
|---|---|---|
| 手机 | 扫二维码传上去的 | 能删，也能一键清空 |
| 本地 | U 盘 / 文件管理器拷进 `media/` 的 | 能删 |
| 远端 | 电脑端清单同步下来的 | 不给删，要下架得改电脑端清单 |

- 删掉后十几秒内生效，电视自动重排，不用重启、不用等一轮播完
- 删的正好是正在播的那条：停在原位置往下播，不跳回第一条重头开始
- 删别的素材：正在播的不被打断，视频不会闪一下重来
- 远端那几条不给删，是因为删了下次同步（默认 5 分钟）又会自己下回来，看到「删了又回来」比不给删更糊涂。要下架远端素材就改电脑端清单，端侧配置里 `prune` 打开的话本地文件也会被顺手清掉
- 文件名以 `.` 开头的（上传写到一半的临时文件）不出现在列表里

### 看素材内容

列表每行左边是缩略图，点缩略图或文件名：

- 图片：看大图
- 视频：直接在手机上播，能拖进度条（电视端支持 `Range` 分段传输）
- 底下有「上一条 / 下一条」连着翻，按 `Esc` 或点黑底关掉

缩略图是原图直接缩小的，电视端不装图像库所以不做压缩。一屏三十张几 MB 的大图，首屏会慢几秒、也走几十 MB 流量（做了懒加载，滚到才拉）。视频不生成首帧，只显示一个 ▶ 标记，点开才真加载。

### 在手机上改服务器地址

远端清单的配置（清单地址、设备名、刷新间隔）也能扫码在手机上改，不用跑到店里 `adb push`：

1. 扫码打开上传页，往下拉到「电脑端清单（服务器地址）」
2. 填清单地址。10 台屏可以共用一份地址，在地址里写 `{device}` 占位，每台只改设备名
3. 先按「先测一下能不能连上」：它会回报清单有几项、版本号多少，还会顺手戳一下第一条素材（「清单拉得到、素材却取不到」是最隐蔽的坑）
4. 没问题再按「保存并立即同步」，电视马上去拉一次，不用等下一个刷新周期
5. 「关掉远端，只用本地目录」：删掉配置文件退回本地模式，清单和已同步的素材都留着

改的就是素材根目录下那份 `signage-remote.json`（U 盘照样能改同一份）。写的时候先落临时文件再改名，拔电不会留下半截配置把电视卡成黑屏。

### 设访问码

上传页是局域网里谁都能打开的：同一个 WiFi 下，任何手机输个 IP 就能看素材、删素材、改服务器地址。不设就不拦人。设一次之后所有操作都要先输码。

手机上打开上传页，拉到「访问码（保护这个上传页）」：

- 填「新访问码」（至少 4 位，中文也行）+ 再输一遍 → 「保存访问码」。当时那台手机不用重登
- 想撤掉：填上当前码 → 「关掉访问码（局域网内谁都能用）」
- 改完之后别的手机上的登录立刻失效，下次要输新码（登录状态本身记 14 天）

访问码存在素材根目录下的 `signage-upload.json`（跟 `signage-remote.json` 并排，U 盘可见）：

```json
{
  "code": "你的访问码",
  "note": "手机上传页的访问码。删掉这个文件就恢复成不需要访问码"
}
```

忘了访问码：把 U 盘插到电视上、或用电视自带的文件管理器删掉这个文件，页面就恢复成不用码。码放在公开目录而不是 App 私有目录，就是为了留这条后路，不然只能重装 APK。

其它几点：

- 默认不设码。店里都是自己人、电视也不对外的话，多一道门只是天天给自己添麻烦
- 访问码文件坏了当作没设（读不出来就当没这道门），宁可门开着也不能把自己锁在门外
- 凭证是访问码的 HMAC，改码 = 把所有已登录的手机一次性踢掉，不需要另存密钥文件
- 没登录时数据接口一律回 401 且带 `needLogin`，页面据此弹登录层。上传被拒时也会先把请求体读干净再回，免得手机报「网络中断」，把「该输码了」伪装成网络故障
- `/status` 里有一行访问码状态（`uploadCodeSet`）
- 设了码，电视上也要过同一道门：点屏（或遥控器「确定」/「菜单」）先弹「需要访问码」，输对了才显示二维码。二维码就贴在店里这块屏上，谁走过都能扫，扫到就能删素材、改地址、把码关掉。通过后 5 分钟内再点不用重输，连错 5 次冷 60 秒。没设码时点屏直接出码

### 触摸屏

- 点一下屏幕呼出二维码（设了码先输一次码），再点一下收起。触屏一体机不需要遥控器
- 认证那一层的按钮能直接点（会弹输入法）；遥控器机型用数字键输码、按「确定」提交、「返回」取消
- 用的是「轻点」判定，滑动、擦拭屏幕不会误弹
- 触摸和遥控器两种方式同时可用。不想要触摸呼出，把 `Config.kt` 里 `TOUCH_TAP_ENABLED` 改成 `false`

### 几个细节

- 传上去的东西放素材根目录下的 `manual/`（通常 `/sdcard/signage/manual`），和本地目录 `media/`、远端目录 `remote/` 完全隔离，谁也不会覆盖谁
- 手机传的内容永远排在播放列表最前面，传完立刻跳过去播；配了远端清单也一样，而且不会被远端同步清掉
- 上传中不打断广告：二维码是叠在画面上的浮层，底下的视频照常播
- 屏幕上一片空白（提示「还没有素材」）时二维码自动弹出来，一旦有内容开始播就自动收掉。设了访问码时自动弹的是认证那一层，否则把素材删空就能白拿到二维码
- 二维码边长 = 屏幕短边的 34%（320～1000 像素之间）。电视屏幕密度普遍偏低，写死 dp 会在屏上显小、手机扫不动，所以按实际像素算，1080p 的屏上是 367px
- 端口默认 8080，被占用会自动往后试到 8091，二维码里的地址就是实际端口
- 没连局域网时，屏幕上直接写明「没有检测到局域网地址」

### 两个坑

1. 手机和电视必须在同一个网段。电视插网线、手机连 WiFi 时，路由器可能把它们分到不同网段
2. 有些路由器开了「AP 隔离」或「访客网络隔离」，同一个 WiFi 下的设备互相访问不了。表现是扫码后页面打不开、或一直转圈。关掉 AP 隔离，或者让手机连主 WiFi 而不是访客网络

这个功能靠电视自己监听端口，只在店里的局域网内可用，不需要任何外部服务器，素材不会跑到公网上。

## 七、出问题了怎么查

电视系统没有 adb，屏幕上也不显示日志，所以做了个状态页，用手机看：

1. 点一下屏幕，二维码浮出来，二维码下面那行地址就是电视的上传服务地址，形如 `http://192.168.1.5:8080/`
2. 手机浏览器打开这个地址，页面最下面有个「查看播放状态」按钮
3. 点它，能看到：

```
版本：门店屏 v0.3.9 (12)
模式：本地目录　触屏点击：开
上传地址：http://192.168.1.5:8080/

【播放】共 4 条，当前第 2 条：02_新品海报.jpg
　播放中：是（图片）　已播 3 秒
　连续失败：0
　上次错误：图片解码失败：xx.jpg

【存储】/sdcard/signage　公共目录（实测可写）
　· 可写　 /sdcard/signage
　· 可写　 /storage/emulated/0/Android/data/com.laodao.signage/files
　· 可写　 /data/user/0/com.laodao.signage/files

【本地目录 media】/sdcard/signage/media
  1. 01_开业促销.mp4  12.3 MB
  2. 02_新品海报.jpg  840 KB

【手机上传 manual】/sdcard/signage/manual
  （空）

【远端 remote】/sdcard/signage/remote/media
  （空）
```

对照着看，基本一眼能定位：

| 现象 | 看哪里 | 说明 |
|---|---|---|
| 传了/拷了不播 | 【播放】总条数 | 是 0 说明目录里没扫到文件，看下面三个目录列表核对路径和文件名 |
| 同上 | 目录列表 | 列出来的才是真被认到的。没有你的文件就是路径不对，或扩展名不在支持范围 |
| 手机上传来好几个、成功 0 个 | 【存储】 | 落盘失败。看「可写」那一行，全不可写就是电视存储有问题，插张 SD 卡再试 |
| 电视上找不到素材目录 | 【存储】第一行 | 那就是实际用的根目录。显示「内部私有目录」说明没拿到存储权限，只能靠手机上传 |
| 屏幕提示「素材都无法播放」 | 上次错误 | 一般是图片格式不认识或文件损坏 |
| 播着播着不动了 | 播放中 + 已播秒数 | 已播秒数巨大就是卡住了，看门狗 15 分钟会自动跳过 |
| 手机上删不掉某条 | 列表前的标签 | 标「远端」的是故意不给删（改电脑端清单下架）；手机/本地的删不掉，页面会写明原因，一般是只读或文件正被占用 |
| 点屏幕先要访问码，不记得了 | 电视上那层认证浮层 | 这台电视设过码。插 U 盘、或用电视文件管理器删掉素材根目录的 `signage-upload.json`，点屏就恢复成直接出码（浮层上也写着这句） |
| 手机打开上传页先让输码 | 页面上「访问码」卡片 | 这台电视设过码。输一次就行，登录状态记 14 天。忘了就删电视上的 `signage-upload.json` |

支持的格式：图片 `jpg / jpeg / png / webp / bmp`；视频 `mp4 / mkv / webm / ts / mov / m4v / avi / 3gp`。其它扩展名一律不认（`.gif`、`.heic` 不在列表里）。

浏览器里直接打开 `http://电视IP:8080/status` 也行，看到的是同一份原始 JSON。

## 八、开机自启

前两条都要做。

1. **设成「桌面」（最稳）**：打开 `app/src/main/AndroidManifest.xml`，把 `HOME` 那段 `intent-filter` 的注释取消掉，重新打包安装。然后在电视上按 Home 键（触屏一体机在 `设置 → 主屏幕 / 默认应用` 里选），选「始终」用「门店屏」打开。系统开机后自己就会把播放界面拉起来，不依赖任何广播
2. **加入自启动白名单（必做）**：电视 `设置` → `应用管理` → `门店屏` → 打开「自启动 / 允许后台运行」。国内品牌电视不加这一步，开机广播大概率收不到或被拦
3. **开机广播（补充）**：已写在 `BootReceiver.kt`。Android 10 以后系统会拦截「后台启动界面」，原生系统上可能被静默丢弃

## 九、常改的参数

都在 `app/src/main/java/com/laodao/signage/Config.kt`：

| 参数 | 默认 | 说明 |
|---|---|---|
| `IMAGE_DURATION_MS` | `8000` | 图片停留毫秒数（清单里写了 `durationSec` 的以清单为准） |
| `MUTED` | `true` | 是否静音 |
| `IMAGE_FIT_CENTER` | `true` | `true` 等比缩放留黑边；`false` 铺满屏幕会裁切 |
| `LOCAL_RESCAN_MS` | `15000` | 本地模式下多久重扫一次素材目录（新拷的立刻上屏） |
| `PLAY_WATCHDOG_MS` | `900000` | 一条内容播超过这么久就认为卡住，强制跳下一条（15 分钟） |
| `EMPTY_RETRY_MS` | `10000` | 全部素材都播不了时多久重试一次 |
| `DEFAULT_REFRESH_SEC` | `300` | 拉清单的默认间隔 |
| `HTTP_TIMEOUT_MS` | `15000` | 拉清单超时 |
| `DOWNLOAD_TIMEOUT_MS` | `120000` | 单个素材下载超时 |
| `UPLOAD_ENABLED` | `true` | 手机扫码上传总开关。关掉就不监听端口、不显示二维码 |
| `UPLOAD_PORT` | `8080` | 上传服务起始端口 |
| `UPLOAD_MAX_BYTES` | `512 MB` | 单个上传文件上限 |
| `QR_AUTO_HIDE_MS` | `120000` | 二维码浮层多久自动收起（触屏上要掏手机连 WiFi，留宽一点） |
| `AUTH_AUTO_HIDE_MS` | `120000` | 认证浮层多久自动收起（有人点开就走开，不能一直盖着广告） |
| `TOUCH_TAP_ENABLED` | `true` | 触摸屏：点屏幕呼出/收起二维码。关掉就只认遥控器按键 |
| `QR_SIZE_RATIO` | `0.34` | 二维码边长 = 屏幕短边 × 它。改大更好扫，改小不挡画面 |
| `QR_SIZE_MIN_PX` / `QR_SIZE_MAX_PX` | `320` / `1000` | 二维码边长的上下限（像素） |

「点屏先认证」那几个参数在 `UploadAuth.kt` 里（跟访问码本身放一起）：

| 参数 | 默认值 | 说明 |
|---|---|---|
| `GRACE_MS` | `300000` | 认证通过后多久内再点屏不用重输（5 分钟） |
| `TRY_LIMIT` | `5` | 连错几次开始冷却 |
| `COOLDOWN_MS` | `60000` | 冷却多久（1 分钟） |

## 十、已知限制

- 图片与视频切换时可能闪一下黑，现在靠切显隐实现，双图层预加载留到第 4 步一起做
- 解码能力取决于电视。老电视播 1080p 可能吃力，卡顿就把素材统一压到 720p
- 手机上传不校验内容，只按扩展名判断是不是图片/视频，传进来的直接播。自己店里用没问题，**别把端口暴露到公网**
- 改服务器地址要在店里（那个设置在电视自己的页面上，只能连同一个 WiFi 时打开）。不在店里想改地址，还是得 U 盘改 `signage-remote.json`
- 没有定时重启和崩溃自恢复：播放看门狗有了，进程级的自恢复还在第 4 步
- 返回键没封，现在能退出到系统桌面（方便调试），第 4 步做 Kiosk 时再彻底封死
- 清单不会自动发布：素材换了要有人点一次发布（网页后台点一下，或跑 `publish.py`）。没做「改完自动生效」，发布这个动作留给人
- 网页后台看不到「屏上正在播什么画面」：状态回传只报「第几条 / 文件名」，不截屏。要真看画面得去店里，或者再加一路截图上报（代价大，暂时不做）
